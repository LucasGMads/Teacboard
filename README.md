# 🌤️ ClimApp

O ClimApp é um projeto simples de previsão do tempo que desenvolvi para praticar meus conhecimentos em **HTML e CSS**.

A ideia foi criar uma página de clima com informações como temperatura, condição do tempo, umidade e velocidade do vento, além de uma previsão para os próximos dias.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Media Queries
* Git

## 📌 Sobre o projeto

Esse projeto faz parte dos meus estudos de **Front-End**. Durante o desenvolvimento, pratiquei a criação de layouts, organização dos elementos com Flexbox, estilização com CSS e adaptação da página para telas menores.

Também utilizei **Git e GitHub** para aprender a trabalhar com branches, commits e Pull Requests.

## 📱 Responsividade

O ClimApp foi desenvolvido para funcionar tanto em computadores quanto em dispositivos móveis.

No celular, os elementos são reorganizados para facilitar a visualização e os cards da previsão se adaptam ao tamanho da tela.

## 🎯 Objetivo

O principal objetivo deste projeto foi colocar em prática o que estou aprendendo sobre desenvolvimento Front-End e entender melhor como HTML e CSS trabalham juntos na construção de uma página.
